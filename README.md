# RCGK — Gestão de Eventos (app)

App instalável (PWA) da RCGK Produções. A tela fica aqui (GitHub Pages); os dados vêm do Agendor
pela planilha "Base Agendor - RCGK" e pelo Apps Script, com login próprio por e-mail e senha.

Não há dados de clientes nem senhas neste repositório.

- Instalar no iPhone: abrir no Safari → Compartilhar → "Adicionar à Tela de Início".
- Instalar no Android: abrir no Chrome → menu ⋮ → "Instalar app".
